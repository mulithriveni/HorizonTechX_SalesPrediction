# 📈 Sales Prediction Using Python

## 📌 Project Overview

This project is developed as part of the Horizon TechX Data Science Internship Program.

The objective of this project is to predict future sales using Machine Learning techniques based on advertising and marketing data.

---

## 🚀 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

---

## 📂 Dataset

The dataset contains advertising information such as:

* TV Advertising Budget
* Radio Advertising Budget
* Newspaper Advertising Budget

Target:

* Sales

---

## 🤖 Machine Learning Model

This project uses:

* Linear Regression

---

## 📊 Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Prediction
8. Model Evaluation
9. Visualization

---

## 📈 Output

The model predicts future sales with good accuracy.

---

## ▶️ How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the dataset file (`Advertising.csv`).
3. Run all cells.
